# 低流量审核（默认）

只优化送给模型看的图片与重复展示。沿用现有抽样、选区、150伤害、横幅、弹药、切点、复核及导出规则；不降低审核覆盖，不改成片分辨率、帧率、编码或声音。源视频和导出始终由本地脚本处理。原始截图和正式证据路径不改、不压缩、不覆盖。

## 默认展示入口

查看本任务图片前，先用正式入口生成本地传输预览，再实际打开输出的 next_paths：

    python apex.py preview --workdir WORK --images PAGE_OR_CROP ...

已生成的HUD/横幅/弹药拼图或裁图用默认page，保持全部像素尺寸，不重复裁剪。
从完整原帧查数字时用 --region stats 或 --region ammo；查横幅用 --region event（同时保留现有HIGH和LOW两个区域，未丢失任一时间点）。区域取自本任务已校准配置，不另改ROI。
全画面布局检查可用 --region context，仅此模式缩成960×540以内；此图不能用于读小字或否定事件。需要看全图文字或核实视角时使用 --region full --detail。

默认JPEG质量82、4:4:4，文字裁图与拼图不缩小像素。已有原图更小就直接沿用。脚本不联网、不传视频、不自动判读，也不把生成预览当成实际审核。

## 看不清就升级

压缩后任何伤害数字、击倒/助攻文字、视角标签、武器图标或弹药不清：同一时间点先 --detail；仍不清用 --lossless 或直接看对应原始证据。要核实本人视角、跨局、争议或原规则要求完整原帧时，保留所需全图核查。不能因省流量填0、判负例、跳页、漏帧或提前停止复核。升级只作用于疑难图，不批量重复上传已经清楚的图片。

## 同任务去重

preview缓存按工作目录、源任务身份、原图内容、区域和清晰度区分。manifest保留每个输入原图到展示图的映射；完全相同图片可只展示一次，但所有时间点和页码仍参与原来的审核。跨任务、源/配置/区域改变或证据变化，不把旧的语义结论直接套过来。

只在实际打开并看完对应图片后登记：

    python apex.py preview-seen --workdir WORK --manifest BATCH_JSON --paths VIEWED_IMAGE ... --reviewer REVIEWER

此记录仅表示传输预览已看过，不会改HUD、事件、页审核、弹药、切点或正式审核状态。already_seen只是减少不必要的重复展示，不能替代原规则要求的独立复核、争议复核或正式导入。需要复核时从manifest取图重新看，不能因去重而跳过。

主代理与工作者沿用原来各自责任和有效审核缓存；清楚且已有效审核的同一图片不用反复展示，冲突及不确定证据仍按原规则回看。结构化结果只传必要字段和异常，不向聊天打印图片base64或整份长日志。

正式hud-import、mark、admission-review-import、ammo-review-import、interval-import、damage-review-import依旧绑定原始证据；不要把review_transfer里的预览替换成正式证据。实际节省只能按应用流量统计计量，脚本报告的只是本地原图/预览文件字节数。
